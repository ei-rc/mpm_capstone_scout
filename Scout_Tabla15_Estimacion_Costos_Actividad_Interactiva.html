La estimación desagrega el costo del proyecto a partir de las actividades planificadas, sus conceptos de gasto, las categorías presupuestarias y el método utilizado para calcular cada monto. Esta estructura permite relacionar directamente la línea base de costos con la EDT, el cronograma y los entregables establecidos para el piloto.
